# YAFM: Yet Another File Manager

Файловый менеджер для Android: память телефона, root и сетевые серверы, со встроенным видео- и аудиоплеером.

[English version](README.md)

## Возможности

### Файлы
- Память телефона и вся файловая система через root (KernelSU, Magisk, APatch).
- Копирование и перемещение между любыми хранилищами: телефон, root, SFTP, qsh, SMB, FTP. Если имя занято, добавляется « (1)», ничего не перезаписывается.
- Категории на главном экране показывают все изображения, видео, музыку, документы или архивы во внутренней памяти, по папкам. Файлы папки выделяются одним нажатием, а категорию можно сузить до нескольких типов (например, pdf и docx).
- Недавние: файлы, добавленные или изменённые за 30 дней, по дням, с пометкой «добавлен» или «изменён».
- Избранные папки на главном экране, из любого хранилища. Сортировка, типы файлов и вид список/сетка запоминаются для каждой папки; папки в категориях сворачиваются.
- Дубликаты: файлы с одинаковым содержимым под любыми именами, в категории или в папке со всеми подпапками. Остаётся копия вне папок мессенджеров и кэша.
- Превью картинок и видео, подписи типа на иконках (PDF, Word, ZIP...), список и сетка, поиск, сортировка, скрытые файлы.
- Отправка файлов в другие приложения, обратное выделение, открытие любого файла как текста. Для файлов из «Открыть в» есть выбор действий.
- Пакетное переименование, права (chmod), свойства файла с MD5 и SHA-256. В продвинутом режиме можно создавать ссылки (root-папки и SFTP).
- Фото: простой редактор (поворот, отражение, размер, кисть), сохраняющий дату и место съёмки, и чистые копии без метаданных, чтобы делиться.
- При удалении и копировании папок ссылки не раскрываются: удаляется сама ссылка, а не то, на что она указывает.

### Архивы
- Формат определяется по содержимому, а не по имени: zip, 7z, tar, ar и cpio, сжатые gz, bz2, xz, lzma, zstd, lz4, snappy, Z или brotli, а также одиночные сжатые файлы.
- Создание: zip, 7z, tar, tar.gz, tar.bz2, tar.xz, tar.zst и tar.lz4.
- Файлы пишутся только внутрь выбранной папки; ссылки и устройства из архива пропускаются. Существующие файлы остаются, пропускаются или заменяются, как выбрано.

### Плееры
- Видео: libVLC, поэтому открывается почти любой формат (mkv с AC3/DTS, avi, wmv, flv...). Жесты для перемотки, яркости и громкости, выбор звуковой дорожки и субтитров, скорость, режимы кадра, блокировка экрана, продолжение с места остановки, следующее и предыдущее видео в папке. При открытии видео можно выбрать: встроенный плеер или другое приложение.
- Музыка: играет в фоне, с системным уведомлением и управлением с экрана блокировки, обложками, перемешиванием, повтором и треками папки в очереди по кругу (и из категории «Музыка»); уведомление открывает плеер.

### Сетевые хранилища
- **SFTP** (SSH): одно соединение на сервер; ключ сервера запоминается при первом входе, изменённый ключ отклоняется.
- **qsh** (SSH поверх QUIC с запасным TCP): просмотр через sftp-подсистему сервера, копирование через `qsh cp`. Вход по ключу телефона: связать по коду из `qshd pair` или добавить на сервер ключ из настроек. Одноразовые коды (2FA) спрашиваются, когда сервер их требует.
- **SMB** 2/3 (общие папки Windows, NAS) и **FTP** (без шифрования, только для доверенной сети).
- Сохранённые пароли шифруются ключом из Android Keystore.

### Прочее
- Менеджер приложений с бэкапом APK, анализ хранилища по типам, root-консоль (в том числе кто больше всего грузит ЦП и ОЗУ), текстовый редактор.
- Темы: как в системе, светлая, тёмная и чёрная AMOLED, цвета обоев. Портретная и альбомная ориентация.
- Обновления из релизов GitHub, проверка при запуске (можно выключить).
- Английский и русский языки.

## Сборка

```bash
# один раз: положить клиент qsh в APK (архив qsh-aarch64-android.tar.gz из релизов qsh)
scripts/fetch-qsh.sh <URL или путь к qsh-aarch64-android.tar.gz>
./gradlew assembleDebug
```

Без `libqsh.so` приложение собирается и работает, недоступны только подключения qsh. Сборка только под arm64-v8a.

Release-сборка подписывается, если в `~/.gradle/gradle.properties` заданы `YAFM_STORE_FILE`, `YAFM_STORE_PASSWORD` и `YAFM_KEY_ALIAS`.

```bash
./gradlew :app:testDebugUnitTest   # SFTP-клиент, архивы, удаление, сравнение версий
```

## Требования

Android 8.0 или новее, arm64.
